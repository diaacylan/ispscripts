How to use this result
The result is a short decision tree. Run the commands in order and record what changes. If discovery is absent, RADIUS is not yet involved. If RADIUS requests time out, test routing and UDP before changing user passwords.
  1. Run one test login while following the relevant log topics.
  2. Change only one variable at a time.
  3. Confirm the result with /radius monitor, counters, and the RADIUS server log.
