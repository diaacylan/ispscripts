What this site does not do

The RouterOS generators on this site (PPPoE + RADIUS, Hotspot + RADIUS, NAT + Firewall) run entirely in your browser. The interface names, IP addresses, and RADIUS secrets you type in are used only to build the script shown on screen — none of it is transmitted to any server, stored in any database, or logged anywhere. This site has no backend server for the generators to talk to even if it wanted to: closing the tab clears everything you entered, permanently.

There is no account system, no login, and no contact form on this site — the contact page links to a plain email address, so any message you choose to send goes directly to that inbox and nowhere else.
