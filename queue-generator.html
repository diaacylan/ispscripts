MikroTik Queue Generator for ISP Bandwidth Plans

Make the Queue Tree policy visible without hiding the packet marks and parent assumptions it depends on.

Free to use · Runs locally in your browser · Last reviewed 2026-09-26
Review before deployment: This page provides a simple Queue Tree-capable plan and keeps parent interfaces and packet marks explicit. A Queue Tree without matching marks can be perfectly valid syntax and still shape nothing.

Change an input to recalculate.
How to use this result
Use Queue Tree when your classification policy is already understood: mark packets in Mangle, attach child queues to the right parent, then watch counters. If you only need a target-based cap, use the Simple Queue Generator instead.
