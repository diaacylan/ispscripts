Why these tools are connected

An ISP deployment is a chain: address planning affects pools, pools affect PPPoE and DHCP, PPPoE may depend on RADIUS, VLANs define the path, queues shape the resulting traffic, and firewall rules protect the router and subscribers. Each page explains the assumptions that connect its output to the next decision.

Safe workflow

  1. Export a backup and record the current RouterOS version.
  2. Plan addresses and interfaces before generating commands.
  3. Apply one small change to one test segment.
  4. Check logs, counters, active sessions, and user experience.
  5. Keep the generated file and rollback command with the change record.
